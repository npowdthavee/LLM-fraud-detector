# Expert validation IRB materials

Supporting documents for the NTU IRB application covering the five-expert validation of the 14 financial-investment scenarios used in the LLM financial-advice study.

Current study details:
- IRB reference: **IRB-2026-1174**
- Target: **5 completed expert validators**
- Estimated duration: **10–15 minutes**
- Compensation: **US$3 via Prolific**

Contents:
- Study protocol
- Participant information and e-consent
- Prolific recruitment and eligibility
- Survey instrument
- Data management and confidentiality plan
- Exempt Category 2 / e-consent justification
- IRB submission checklist
- Qualtrics QSF draft

These materials are pre-registration-stage study-development documents. Final approved versions should replace draft versions after IRB review.
